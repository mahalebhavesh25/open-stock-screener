# Open Stock Screener

An accessible, open-source stock screening web application designed to bridge the gap between quantitative financial analysis and everyday retail investors.

## Overview

Most quantitative stock screeners require deep knowledge of financial modeling, complex query syntax, or trading jargon. **Open Stock Screener** simplifies market discovery by allowing non-technical users without a finance or trading background to screen, filter, and understand equities intuitively.

## Planned Features

- **Plain-English Filtering:** Screen stocks using intuitive, everyday criteria instead of complex financial formulas.
- **Quantitative Metrics Made Simple:** Built-in explanations and visual breakdowns for key indicators (P/E ratio, market cap, moving averages, volume trends).
- **Custom Watchlists & Alerts:** Save screening presets and track market movements easily.
- **Modular Data Pipeline:** Clean architecture designed for easy integration with open financial market APIs.

## Project Status

**Early Development (Work in Progress)**  
Core architecture and screening logic are currently under active development. Contributions, ideas, and feedback will be welcomed once the initial prototype is pushed.
